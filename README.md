# Groundnbn

Airbnb-style booking platform developed as a university course project.

## Features

- User authentication and registration
- Create listings
- Browse listings
- Property details page
- Booking system
- Wishlist
- My Listings
- My Bookings
- Filtering
- Reviews and comments

## Tech Stack

- React
- JavaScript
- React Router
- React Hook Form
- Axios
- REST API
- CSS
- Vite
